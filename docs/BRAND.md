# 实证研策品牌识别

日期：2026-10-14。品牌规范版本：0.1；适用于当前 Yantra 0.3.3 工作区。状态：已确认设计方向的矢量初稿，尚未作为产品界面或报告默认样式集成。

## 定位与设计方向

主名称为「实证研策」，英文名为「Yantra」。面向个人投资研究者，定位为帮助研究者校准判断的精密工具。采用旧式科学仪器说明书的理性复古风格，以宋体、纸墨色和留白表达东方气质。

用户已选择 A：两端渐细的开放圆弧、右侧五根刻度、圆弧缺口上方悬置的鲜朱砂点。朱砂点保持当前位置。避免贯穿圆心的十字线、靶心、山水装饰和密集宗教图式。符号是视觉隐喻，不表示实际测量精度或研究正确率。

## 色彩

以下为本轮矢量稿的精确 sRGB 色值，不是从生成草图中精确取样。印刷 CMYK 与专色尚未校样。

| 色彩 | 色值 | 用途 |
|---|---|---|
| 墨褐 | `#30251D` | 符号、字标、主文字与深底 |
| 纸白 | `#F7F3EA` | 浅底与反白标志 |
| 鲜朱砂 | `#E12B22` | 读数点与少量强调 |

朱砂不是涨跌颜色或成功状态色。数据图表必须另外定义有明确语义的颜色及文字标注。

## 字体与组合

中文初稿使用本机 Songti SC 的 600 字重，英文使用 Times New Roman。SVG 内保留可编辑文字，未嵌入字体、未转曲；缺少字体时回退会改变字形和宽度。本轮没有分发字体文件或完成字体许可审查，发布前须确认许可并以转曲文件固定字标。正文、界面和数字字体尚未定稿。

符号坐标框为 280 × 280；横排组合为 760 × 280，竖排为 460 × 440。以 SVG 原始比例等比缩放，不拉伸、不移动朱砂点、不独立改动刻度数量或字标间距。圆弧由封闭填充路径组成，保证两端渐细；刻度线宽为 4 个坐标单位，朱砂点直径为 14 个坐标单位。

## 留白与尺寸

暂定额外安全留白为符号坐标框宽度的 10%，从整体可见图形边界向外计算；画板内空白不能代替外部安全留白。

本轮渲染查看了独立符号的 64、48、32、24 像素坐标框。48 像素暂定为建议最小尺寸，32 与 24 像素刻度明显变弱，尚未提供小图标专用版本。组合标志建议至少 240 像素宽；这是初稿使用建议，未完成跨设备、印刷及所有背景的验收。不要将预览图中的小尺寸展示当作可读性认证。

## 检查与后续边界

本轮使用 macOS Quick Look 渲染预览，人工检查构图、字标、反白与尺寸序列；检查 SVG XML 可解析、引用文件存在及 Git 空白错误。没有运行应用测试，因为本轮没有修改产品行为。

下一阶段需确定字体许可与转曲文件，实际检查各尺寸导出，并完善正文、图表与报告模板。原图生成探索保留在本机 Codex 生成目录，本资产包不依赖这些本机路径。
